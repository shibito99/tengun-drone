# Claude Code「いちいち確認」を9割減らすキット 🚀

クロードコード部のみなさんへ。

Claude Code を使っていると、**「このコマンドを実行してもいいですか？ (y/n)」**
がしょっちゅう出てきて、いちいち止まって面倒……ですよね。

このキットを入れると、**安全なコマンドは自動でOK**になり、その確認が
**約9割減ります**。作業がスッと流れるようになります。

（＝黒川が普段使っている「許可リスト」の設定を、そのままあなたのPCにコピーします）

---

## つかい方（3ステップ・2分）

1. ダウンロードした ZIP を**ダブルクリックで解凍**する
2. 解凍してできたフォルダを**ターミナルで開いて**、下の1行をコピペして実行：

   ```bash
   bash install.sh
   ```

3. **Claude Code を再起動**する（次に立ち上げたときから効きます）

> 💻 対象：Mac / Linux（Macなら最初から動きます）
> Windowsの方はごめんなさい、今回は対象外です。

うまくいったか確認したいときは、Claude Code で `/permissions` と打つと
許可リストが入っているのが見えます。

---

## これって危なくない？（安全のはなし）

安心してください。**乱暴なことは一切しません。**

- 🛡 **危険な操作はむしろブロック**します
  （`rm -rf /`・`sudo`・`.env` や SSH鍵・APIキーの読み取り などは自動で拒否）
- 🧷 あなたの今までの設定（モデル・MCP・トークン等）は**消しません**。
  許可リストの部分だけを足します。
- 💾 実行前に**自動でバックアップ**を取ります（元に戻せます）
- 🔁 何度実行しても結果は同じ（こわれません）

---

## 元に戻したいとき

実行すると `~/.claude/settings.json.bak.（日付）` というバックアップが
できます。戻したいときはそれを元の名前に戻すだけ。詳しくは同封の
`README.md` の「ロールバック」を見てください。
